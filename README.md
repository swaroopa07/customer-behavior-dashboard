Customer Behavior Analytics Dashboard

Project Overview
This project is an interactive Customer Behavior Analytics Dashboard built using 
** Power BI, SQL, Python, and Excel.

It analyzes customer purchasing behavior to uncover insights related to:
- Revenue trends
- Customer demographics
- Product performance
- Discount impact
- Subscription behavior
- Shipping preferences

The goal of this project is to help businesses understand customer segments and improve marketing and sales strategies through data-driven insights.

 Tools Used
- SQL Server
- Python (Pandas,)
- Microsoft Excel
- Power BI

Dataset Overview
The dataset contains customer shopping behavior data with the following attributes:

- Customer ID
- Age & Age Group
- Gender
- Item Purchased
- Category
- Purchase Amount (USD)
- Review Rating
- Subscription Status
- Discount Applied
- Shipping Type
- Payment Method
- Previous Purchases
- Location
- Purchase Frequency

 Key Business Questions Solved (SQL Analysis)
- What is the total revenue generated by male and female customers?
- Which customers used discounts but still spent above average purchase amount?
- Which products have the highest average review rating?
- How does purchase behavior vary by shipping type (Express vs Standard)?
- Do subscribed customers spend more than non-subscribed customers?
- Which products have the highest discount usage rate?
- How can customers be segmented into New, Returning, and Loyal groups?
- What are the top 3 most purchased products in each category?
- Are repeat buyers more likely to become subscribers?
- Which age group contributes the highest revenue?

Key KPIs
- Total Customers
- Total Revenue
- Average Purchase Amount
- Average Review Rating

Key Insights
- Clothing category generated the highest revenue.
- Young Adults contributed the highest share of revenue.
- Female customers showed slightly higher total spending.
- Non-subscribed customers contributed higher total revenue due to larger customer base.
- However, average purchase amount is almost identical for both subscribed and non-subscribed customers.
- Subscription status does not significantly impact per-transaction spending behavior.
- Discount usage is consistently high across top product categories (~47%–50% of purchases).
- Hats, coats, and sneakers show the highest discount adoption rates.
- This indicates that discounts are widely used as part of the purchasing behavior across categories.

Project Workflow
1. Collected and understood customer behavior dataset
2. Cleaned and preprocessed data using Python & Excel
3. Performed exploratory data analysis using SQL
4. Created calculated metrics and transformations in Power BI
5. Built an interactive dashboard with filters and visuals
6. Generated business insights for decision-making
